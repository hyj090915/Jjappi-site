설치와 업데이트

Apple Silicon(M 시리즈) Mac에서 macOS 14 이상을 사용하고 있다면 시작할 수 있어요.

  1. Mac 다운로드에서 다운로드 (.zip) 또는 다운로드 (.dmg)를 고르세요. 둘 다 같은 앱이에요.
  2. ZIP을 받았다면 압축을 풀고 짜삐.app을 응용 프로그램 폴더로 옮기세요. DMG를 받았다면 더블클릭해서 연 창에서 짜삐.app을 Applications 폴더로 끌어 놓으세요.
  3. 짜삐를 열면 바탕화면에 캐릭터가 나타나요. 몸통을 눌러 채팅을 고르거나, 캐릭터를 우클릭해 설정을 여세요.
처음 실행할 때 확인 창이 떠요

공식 다운로드 사이트에서 제공하는 짜삐는 Apple 공증을 받았어요. Mac에서 인터넷으로 받은 앱을 열지 물으면 열기를 누르세요.

새 버전으로 업데이트하려면?

v0.2.2부터는 Mac 화면 위 메뉴 막대의 우사기 아이콘을 우클릭하고 업데이트 확인…을 고르세요. 새 버전이 있으면 안내에 따라 설치하세요. 같은 메뉴에서 자동으로 업데이트 확인을 켜 두면 새 버전이 나올 때 알림을 받아요.

v0.2.1 이하를 사용한다면 짜삐를 완전히 종료하고, 위 설치 순서에 따라 기존 앱을 한 번 교체하세요. 설정과 작업 기억은 그대로 남아요. 버전별 변경 사항 보기

캐릭터 조작과 꾸미기

캐릭터를 잡고 끌면 위치가 바뀌어요. 마우스를 올리면 나타나는 오른쪽 아래 손잡이를 끌어 크기를 조절하세요. 우클릭이나 Control + 클릭으로 설정창을 열 수 있어요.

캐릭터와 이름
설정 → 일반 → 캐릭터에서 원하는 친구를 고르세요. 이름을 입력하고 저장을 누르면 채팅에서도 그 이름을 사용해요. 표정과 움직임 미리보기에서 표정을 눌러 볼 수 있어요.
크기와 움직임
크기는 80~480px 사이로 맞출 수 있어요. 다른 창 위에 표시할지, 모든 데스크톱에 보일지, 움직임을 줄일지도 같은 화면에서 정해요.
잠깐 접어 두기
아래의 −를 누르면 작은 버튼으로 접히고, 다시 누르면 펼쳐져요. 접힌 동안에도 켜 둔 알림은 도착해요. 숨긴 캐릭터는 Mac 메뉴 막대의 짜삐 메뉴에서 캐릭터 다시 보이기로 불러오세요.
캐릭터 소리와 빼꼼을 바꾸려면?

우사기는 머리 옆 스피커를 눌러 반응 소리를 켜거나 끌 수 있어요. 종은 메신저 알림을 조절해요. 설정 → 일반 → 가끔 빼꼼을 켜면 설정창 가장자리에서 캐릭터가 잠시 고개를 내밀어요. 눌러서 바로 숨길 수도 있어요.

AI 연결과 채팅

먼저 대답할 AI를 연결하고, 채팅은 바탕화면에서 가볍게 시작하세요.

  1. 설정 → 일반 → AI 연결에서 제공자를 선택하세요. 구독으로 쓰려면 GPT · ChatGPT 구독 또는 Claude · 구독 계정을 고르고 해당 서비스의 로그인 안내를 따라가세요. Gemini는 API 키로 연결해요.
  2. 필요하면 모델과 추론 단계를 고른 뒤 연결 설정 저장 → 연결 테스트를 누르세요. 이 Mac에서 구동 중인 Ollama 모델도 선택할 수 있어요.
  3. 캐릭터 몸통 → AI와 대화를 누르고 메시지를 쓰세요. Enter로 보내고 Shift + Enter로 줄을 바꿔요. 곁채팅의 ↗를 누르면 같은 대화를 큰 창에서 이어 가요.

작업 진행 상황과 구독 한도는 어디서 봐요?

채팅의 진행 표시를 펼치면 현재 단계와 경과 시간을 볼 수 있어요. 작업 중에 추가 지시를 보내거나 중단할 수도 있어요. 지원되는 구독 연결에서는 채팅 오른쪽 아래 원형 표시에 마우스를 올려 제공자가 알려 준 한도와 갱신 시각을 확인해요.

검색과 파일·컴퓨터 작업

GPT 또는 Claude 구독 연결에서 채팅 입력창의 작업 모드를 고르세요. 자동으로 두면 요청에 맞춰 모드를 선택해요.

웹검색
“오늘 발표된 소식을 찾아서 출처와 함께 정리해 줘.”
파일 정리
폴더 선택 후 “이 폴더의 PDF를 한곳에 모아 줘.” 계획의 대상과 경로를 확인하고, 이동은 정리 실행, ZIP 압축은 압축 실행을 누르세요.
작업·조작
“선택한 폴더에 회의록.md를 만들어 줘.” 파일 작성, 명령 실행, 화면 확인이나 앱 조작을 요청할 수 있어요.
승인 방식과 Mac 권한을 바꾸려면?

입력창의 승인 요청을 누르면 내 대신 승인, 전체 권한을 포함한 각 방식의 범위가 나와요. 직접 확인하려면 승인 카드에서 파일 경로와 작업 내용을 읽고 이번만 허용 또는 거절을 선택하세요.

앱 클릭·입력에는 macOS 접근성, 화면 캡처에는 화면 기록 권한이 필요해요. 설정 → 일반 → 컴퓨터 작업 권한에서 열 수 있어요. 화면을 AI에게 보여 주는 작업에서는 캡처가 연결한 제공자에 전달될 수 있어요.

작업과 기억

한 채팅에서 여러 일을 번갈아 한다면 일마다 작업을 만들어 두세요. 다음번엔 그 작업의 목표와 기억을 불러와 이어갈 수 있어요.

  1. 설정 → 작업·기억 → 새 작업에서 이름과 목표를 적어요. 채팅의 작업 선택 메뉴에서 이어갈 일을 고르세요.
  2. 기억 남기기로 결정 사항이나 선호를 저장하세요. 저장한 내용을 열어 고치고, 오래 보관할 기억은 고정해요.
  3. 보관 한도를 바꾸고 적용을 누르세요. 저장 공간이 차면 오래되고 중요도가 낮은 내용부터 줄이거나 정리해요.

작업과 기억은 이 Mac에 저장돼요. 외부 AI로 대화하면 답변에 필요한 대화와 관련 기억이 연결한 제공자에게 전달돼요.

메신저 알림과 방 관리

캐릭터 왼쪽 위의 종을 눌러 수신을 켜세요. 한 번 더 눌러 빗금이 생기면 알림이 꺼져요.

처음 연결할 때
알림 → 알림 감시를 켜면 카카오톡·디스코드 알림을 받아요. 권한 설정 열기로 짜삐의 전체 디스크 접근 권한을 허용하고, 메신저 자체의 macOS 알림도 켜 두세요.
메시지 확인
새 알림은 캐릭터 옆 말풍선에 떠요. 숫자에 마우스를 올리면 방별 최신 메시지와 개수가 보여요. 오른쪽 화살표로 이전 메시지를 펼치고, 메시지를 눌러 메신저에서 확인하세요.
받을 방 고르기
새 방은 기본으로 수신해요. 방별 알림에서 방을 끄거나 방 설정에서 포함·제외 키워드를 정하세요. 제외된 채팅 → 알림 다시 받기로 해당 방의 새 알림을 다시 받을 수 있어요.
놓친 알림을 한 번 더 받으려면?

알림에서 미확인 알림 다시 알리기를 켜세요. 현재 목록을 모두 정리하려면 모두 확인을 누르세요.

알림을 눌러도 원하는 방이 열리지 않아요

같은 이름의 방이 있거나 알림에서 목적지를 확인하기 어려울 수 있어요. 카카오톡은 방 연결에 정확한 채팅방 이름을, 디스코드는 해당 채널이나 메시지에서 복사한 링크를 입력하고 연결하고 열기를 누르세요. Mac이 방 탐색 권한을 묻는 경우 접근성에서 짜삐를 허용하세요.

인스타그램 DM

캐릭터 몸통 → 인스타그램 DM을 누르면 Instagram 로그인 또는 받은 메시지함이 열려요. 처음에는 여기서 직접 로그인하고, 대화 목록에서 상대를 골라 메시지를 보내세요. 창 가장자리를 끌어 크기를 바꿀 수 있어요.

짜삐는 이 Mac의 로그인 세션을 다음 실행에도 사용해요. Instagram이 다시 인증을 요구하면 열린 로그인 화면에서 진행하세요. 새 DM의 보낸 사람이나 미리보기를 받지 못한 경우에는 일반 DM 알림을 표시해요.

급식과 카메라 거울

입을 누르면 경북소프트웨어마이스터고등학교의 급식이 떠요. 다시 누르거나 바깥을 클릭해 닫으세요. 다른 날은 생활 → 급식에서 날짜 화살표로 찾고, 지금 급식으로 돌아와요.

눈을 누르면 카메라 거울이 열려요. 처음에 카메라 사용을 허용하고, 다시 눈을 눌러 닫으세요. 카메라가 실시간으로 비추며 사진이나 영상 파일은 저장하지 않아요. 얼굴 클릭 기능은 설정 → 일반 → 클릭 기능에서 각각 켜거나 끌 수 있어요.

음악과 재생 카드

Spotify나 Apple Music에서 곡을 틀고 캐릭터의 귀를 누르세요. 캐릭터에 따라 뿔이나 집게가 같은 역할을 해요. 재생 카드에서 곡을 확인하고 재생·일시정지하거나 다음 곡으로 넘길 수 있어요. 귀를 다시 누르면 카드가 닫혀요.

Chrome 유튜브도 카드에 담기

설정 → 일반 → 클릭 기능 → 유튜브 연결하기를 누르세요. 처음이라면 Chrome 확장 프로그램 화면 오른쪽 위의 개발자 모드를 켜고, 짜삐 도우미의 확장 폴더를 그 화면에 끌어 놓으세요. 관리 화면이 보이지 않으면 Mac 상단의 Chrome 메뉴에서 창 → 확장 프로그램을 누르세요.

드래그가 어렵다면 도우미에서 폴더 경로를 복사하세요. Chrome에서 압축해제된 확장 프로그램을 로드를 누르고, 폴더 선택 창에서 ⌘⇧G → ⌘V → Return을 누른 뒤 폴더를 선택하세요.

이미 확장을 설치했다면 열려 있던 YouTube나 YouTube Music 탭을 새로고침하고 영상을 재생하세요.

귀를 누르면 현재 또는 최근에 재생한 항목이 떠요. 카드를 누르면 Spotify · Apple Music과 재생 소리가 펼쳐져요. 원하는 줄에서 재생을 조작하거나 제목을 눌러 출처로 이동하세요.

웹·앱 바로가기

생활 → 바로가기에서 자주 가는 곳을 모아 두세요. 열고 싶은 곳에 따라 두 가지로 저장할 수 있어요.

자주 가는 곳
추가를 누르고 웹페이지 주소를 입력하거나 앱 선택으로 Mac 앱을 고른 뒤 저장하세요. 목록의 이름을 누르면 열려요.
선택창 서비스
캐릭터를 눌렀을 때 AI와 Instagram 옆에 띄우고 싶은 웹서비스를 추가하세요. 다음부터는 몸통을 누르고 그 서비스를 고르면 작은 창에서 열려요.
